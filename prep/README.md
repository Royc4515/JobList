# Prep kits - interviews and assignments, per company

One folder per process (`prep/<company>-<role>/`). Each holds what Roy needs to prepare,
ready to paste into a fresh session (Claude, Gemini, ChatGPT) or open on a side screen.

| File | What it is |
|---|---|
| `interview-N-research-prompt.md` | Prompt for a research + mock-interview session before interview N |
| `interview-N-notes.html` | One-page notes to keep open during interview N |
| `interview-N-debrief.md` | What happened, what was asked, next steps (written after the call) |
| `*-tutor.md` / `*-coach.md` | System prompt for a practice session (coding exercise, home assignment) |

Rules:
- Before preparing any interview, read the actual invite for the interviewer's name, title,
  format and time (see CLAUDE.md, "Interview prep").
- The repo is public: no phone number, ID number, CV files or transcripts here. Facts already
  in `PROFILE.md` and `applications/` are fine.
- Link the kit from the application file's notes.
